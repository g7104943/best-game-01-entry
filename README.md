COREBREAK: drill 30 levels down a living mountain, manage your drill's heat, draft an upgrade every 5 levels, and slay the 3-phase Core Wyrm — then keep digging in endless mode.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. A/D or arrows move, W jumps, S digs down, push into rock to drill, hold click to aim the drill, E drops a bomb, P pauses, M mutes.
